The following functions are available globally.

  • TVOAudioDeviceFormatChanged

    Deprecated

    Will not be supported in TwilioVoice v7.0+

    This method should be called any time the capturing or rendering format changes. If both formats change simultaneously its fine to call this method just once. As a result the media engine will read the new audio format, stop capturing and/or rendering by calling stopCapturing and/or stopRendering and then call startRendering: and/or startRendering:.

    Declaration

    Objective-C

    void TVOAudioDeviceFormatChanged(TVOAudioDeviceContext _Nonnull context)

    Swift

    func TVOAudioDeviceFormatChanged(_ context: TVOAudioDeviceContext)

    Parameters

    context

    The context pointer. You should use the same context provided in startCapturing: and/or startRendering: here.
  • TVOAudioDeviceReinitialize

    This method should be called when (1) capturing or rendering format is changed, (2) audio device is re-enabled, (3) audio session is uninterrupted, (4) audio route is changed. As a result, the media engine will read the new audio format, stop capturing and/or rendering by calling stopCapturing and/or stopRendering, and then call startRendering: and/or startRendering:.

  • TVOAudioDeviceExecuteWorkerBlock

    A utility method to execute a block on the media engine’s worker thread asynchronously.

    @discussion TVOAudioDevice invokes the callbacks on the media engine’s worker thread. If you wish to initialize, start or stop the audio device from your application code, to avoid the thread-safety problems, you should execute code from the media engine’s worker thread. Example: - (void)handleMediaServiceLost:(NSNotification *)notification { TVOAudioDeviceWorkerBlock workerBlock = ^{ [self stopAudioUnit]; }; TVOAudioDeviceExecuteWorkerBlock(context, workerBlock); }

    Declaration

    Objective-C

    void TVOAudioDeviceExecuteWorkerBlock(TVOAudioDeviceContext _Nonnull context,

    Swift

    func TVOAudioDeviceExecuteWorkerBlock(_ context: TVOAudioDeviceContext, _ block: @escaping TVOAudioDeviceWorkerBlock)

    Parameters

    context

    The context pointer. You should use the same context provided in startRendering: or startCapturing: here.
    block

    A block which will be executed on the media engine’s worker thread.
